QUELQUES ÉTAPES POUR COMMENCER

Du petit au grand écran.

Un téléphone. Une TV compatible.
Le même réseau Wi-Fi.

  1. 01

    Installez le duo.

    Ouvrez l’APK Android sur votre téléphone. Transférez l’APK TV sur votre Android TV ou Google TV, puis installez-le avec son gestionnaire de fichiers. Si Android le demande, autorisez la source de téléchargement choisie.

  2. 02

    Associez les écrans.

    Ouvrez PhoneMirror TV. Sur le téléphone, choisissez Connecter une TV → PhoneMirror TV, puis saisissez l’adresse IP et les six chiffres affichés sur la TV.

  3. 03

    Autorisez le partage.

    Acceptez les demandes Android de capture et d’audio. Réglez la qualité avant de diffuser. Avec PhoneMirror TV à jour, le mode WebRTC se lance automatiquement ; gardez le téléphone déverrouillé.

AVANT DE VOUS LANCER

Les bonnes
informations.

Et pour une TV Samsung ou LG ?+

Les APK Android ne s’installent pas directement sur Samsung Tizen ou LG webOS. Utilisez un Chromecast, une connexion DLNA compatible HLS/H.264/AAC, ou un boîtier Android TV / Google TV avec PhoneMirror TV. La compatibilité dépend du modèle.

Comment fonctionne le son ?+

Le son interne est disponible à partir d’Android 10, après autorisation. Le microphone n’est pas utilisé comme source. Certaines applications empêchent la capture de leur son ou de leur image. Un réglage de décalage audio est disponible dans Qualité.

Est-ce adapté au jeu ou au tactile à distance ?+

Le mode WebRTC avec PhoneMirror TV réduit l'attente liée aux segments vidéo. La réactivité réelle dépend des appareils et du Wi-Fi ; aucune latence de jeu n'est garantie. Google Cast et DLNA restent sur un flux HLS avec davantage de délai. Les APK n'ajoutent pas de contrôle tactile à distance.

Où vérifier les fichiers téléchargés ?+

Les trois APK sont signés. Le récepteur AirPlay est une application séparée. Vous pouvez comparer leur empreinte SHA-256 avec le fichier de vérification. Une ancienne version signée avec une autre clé doit être désinstallée avant cette installation ; sauvegardez d’abord ses éventuelles données utiles.

Quel réseau utiliser ?+

Privilégiez un Wi-Fi de confiance, idéalement 5 GHz. La vidéo et l'audio WebRTC sont chiffrés ; les échanges HTTP locaux et les flux HLS Cast/DLNA ne le sont pas. Éteindre l’écran arrête la capture ; une nouvelle autorisation permet de reprendre. Un changement de réseau peut nécessiter un nouvel appairage.
